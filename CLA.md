## How to sign

When You open your first pull request, a check named **cla** asks You to
sign. Reply to the pull request with this exact comment:

> I have read the Kwerft CLA and I agree to it.

The check records Your GitHub user name and ID, the date, this agreement's
version and the pull request, and passes. You sign once; it covers all Your
later Contributions. Every author of a pull request's commits must have
signed, so commits must be linked to a GitHub account (use the email
address of Your GitHub account in Git).
